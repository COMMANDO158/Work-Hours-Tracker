Setup GitHub Cloud Sync

Sync your data across devices using GitHub Gists. Your data will be stored in a secret gist in your GitHub account.

How to get your token:

  1. Go to GitHub Tokens
  2. Click "Generate new token" → "Generate new token (classic)"
  3. Give it a name like "FlowFocus Sync"
  4. Select "gist" scope only
  5. Click "Generate token" and copy it
  6. On your other devices: paste the same token. They will find and merge with your existing data automatically

Keep this token secret! It gives access to your gists.

Token starts with "ghp_" or "github_pat_"
